# Sequify

Offline Windows video editor with one-click platform formats (YouTube, Shorts, TikTok, Reels, Stories, X, LinkedIn, Facebook, Snapchat, Pinterest, WhatsApp). Edit once, export every version at once. No AI, no cloud, no accounts.

## Download

Get the latest version from the [Releases page](https://github.com/code-dev-env/sequify-releases/releases/latest):

- **Installer**: Setup exe, installs Sequify on your PC
- **Portable**: runs without installing
